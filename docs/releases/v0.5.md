# V0.5 — Hardware provenance and measurement validation

V0.5 establishes the evidence loop without claiming an accuracy target before
measurements exist. Hardware facts carry field, value, unit, source, source
kind, verification date, and published/assumption/calibrated/provisional
status. A100, H100 SXM, H100 PCIe, and B200 expose versioned facts through the
hardware API; all other legacy targets remain explicitly provisional.

The canonical measurement schema records runtime distributions, concrete
shapes, environment, clocks, kernel and candidate identity, optional counters,
the model version, and a link to the raw source. Canonical JSON round-trips
losslessly. Generic CSV and CUTLASS Profiler CSV importers are included.

Accuracy evaluation reports raw median APE, p90 APE, log-RMSE, signed bias,
candidate top-k recall, and groups by hardware, dtype, shape regime, and
bottleneck. A transparent median-ratio scale overlay records every training
record ID and model version. Raw metrics are always available before calibrated
metrics; no initial accuracy threshold is invented in this release.
