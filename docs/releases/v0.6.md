# V0.6 — Reduction and normalization pipelines

V0.6 proves that the explicit resource scheduler is usable beyond GEMM.
Reduction now has row/reduction semantics and auto-selected warp, block, and
two-pass strategies. Two-pass models expose partial-output writes and reloads.

LayerNorm and RMSNorm have distinct FLOP and affine-input accounting, with
one-pass, online, and two-pass strategy selection. Their pipeline decomposition
shows vector loads, shared reduction, barriers, reciprocal square root,
affine/output conversion, and stores. Two-pass normalization exposes partial
statistics traffic rather than hiding it in a compute constant.

Both families emit the same generic pipeline IR used by the resource scheduler;
strict pipeline requests execute a pipeline model and no longer fall back to a
roofline bound. These remain uncalibrated analytical models until measurement
fixtures are collected through the v0.5 measurement schema.
